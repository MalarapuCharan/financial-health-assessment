# Financial Health Assessment Tool

This project evaluates financial risk using basic financial inputs such as
revenue, expenses, cash in hand, loan amount, and receivables.

Users upload a CSV file and receive a risk percentage along with
Low / Medium / High risk classification.

## How to Run
1. Clone the repository
2. Install required dependencies
3. Run the application locally
4. Upload a sample CSV file

## Input Format
CSV columns:
revenue, expenses, cash_in_hand, loan_amount, receivables
